# Latest Nubo for Mac

Current version: 1.0, build 17. Developer ID signed and notarized.

The website uses the stable `main/nubo/mac/latest/Nubo.zip` URL. For each release, replace this ZIP and its SHA-256 checksum with the verified release artifact.
