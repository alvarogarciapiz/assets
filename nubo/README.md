# Nubo for Mac

Free Mac companion for [Nubo](https://nubo.lvrpiz.com/). Requires macOS 15 or later.

## Version 1.0 — build 15

- [Download ZIP](mac/1.0-build15/Nubo-1.0-build15.zip)
- [SHA-256 checksum](mac/1.0-build15/Nubo-1.0-build15.zip.sha256)
- [Sparkle update feed](mac/appcast.xml)

The app is signed with Developer ID and notarized by Apple. Download the ZIP, unzip it, move **Nubo.app** to **Applications**, then open it and follow the permission onboarding. The iPad client is distributed separately through the App Store.

SHA-256: `32541aafe54502d167c80572b7f277684066fd19d84df41b0a601ac62511b39c`.

Build 15 includes Sparkle for future signed updates. Build 10 users need one manual installation of this version. Previous releases remain available in their versioned folders.

Future releases belong in a new version/build directory; do not overwrite an existing release. Public website download links pin a repository commit so the distributed bytes remain reproducible.
